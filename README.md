## Cara pasang
1. Muat naik `source/index.html` (satu fail: HTML + CSS + JS) ke hosting anda — boleh tukar nama, contohnya `index.html`.
2. Tukar nombor WhatsApp (`wa.me/60123456789`) dan e-mel (`hai@hanazulaikha.example`) dalam fail itu.
3. Siap. Gambar, fon (fonts.bunny.net) dan wajah testimoni (avatarmelayu.com) dimuat dari CDN.

## Folder
- `images/landing/` — gambar WebP (dijana AI) + `og.png`.
- `source/` — `index.html` siap pasang, serta `landing.css` / `landing.js` asal yang boleh dibaca.

Tukar gambar? Tolak fail baharu dan buat tag baharu (`1.0.1`), kemudian kemas kini `@1.0.0` dalam `index.html`.
Tag lama tidak boleh dialih — jsDelivr menyimpan cache fail bertag secara kekal.
